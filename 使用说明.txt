Myopic Defocus 1.3.5
===================

1. 完全退出所有旧版，再运行 MyopicDefocus.exe。
2. 托盘右键 → Settings 调整参数；点击 Save 才应用设置窗口里的修改。
3. 参数单位及解释见 docs/参数调整说明.pdf（同时提供 Markdown、TXT 版本）。
4. Ctrl+Alt+F8 关闭/开启滤镜；托盘 Exit 完全退出。
5. 异常时如快捷键无响应：Ctrl+Alt+Delete → 任务管理器 → 结束 MyopicDefocus.exe。

新配置通常位于 %LOCALAPPDATA%\MyopicDefocus\settings.ini。
旧配置会复制并沿用，原文件保留。托盘 Open config file 打开实际文件。

本次审计修复了全屏/局部重绘缓存不一致、部分捕获失败未恢复、恢复句柄泄漏、
无效参数解析、重新启用沿用旧呈现状态及重复计时查询等问题。
详见 BUG-CHECK.md。Windows 实机行为仍需测试；I-Beam 闪烁尚未确认完全解决。

仅处理主显示器横屏。未验证 HDR、DRM、独占全屏、竖屏及多显示器滤镜。
这是实验性视觉滤镜，不是医疗器械或经验证的近视治疗工具。
有视觉不适请停用，不要用本程序替代眼科检查或已有治疗。
