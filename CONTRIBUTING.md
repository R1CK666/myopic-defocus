# Contributing

Please include Windows version, GPU, primary-display resolution/scaling/refresh
rate, optical parameters, rendering flags and reproducible steps. Remove private
information from any screenshots or logs.

Priorities: runtime correctness, safe display recovery, pointer handling and
measurable image fidelity. No medical-benefit claims without appropriate evidence.
Run `python3 source/tests/audit_checks.py` for host math/static checks and validate
changes on real Windows hardware. These are complementary, not interchangeable.
Contributions are under the repository's GPL-3.0-or-later license.
