# Myopic Defocus 参数调整指南
适用版本：1.3.5（审计修正版，仍需实机验证）

## 参数调整指南

Myopic Defocus · 1.3.5
实验性色差离焦滤镜｜Windows 10 2004+ / Windows 11 x64

> **先明确边界**
> 它是屏幕图像滤镜，不是医疗器械。没有证据证明这款程序能控制、治疗或逆转近视，也没有完成长期安全性验证。名称里的“离焦”指所模拟的色差线索，不表示软件能直接改变光线在眼内的聚焦位置。

### 先正确运行，再调整参数

完全退出旧版本，只运行 MyopicDefocus.exe。托盘右键 → Settings 打开设置；填入参数后点击 Save。输入数字的小数部分使用英文句点，例如 6.5。

仅处理主显示器横屏；竖屏、HDR、受保护内容及独占全屏不受支持或未验证。

修改输入框内容时不会连续预览；点击 Save 后才应用，并请求一次全屏重绘。快捷键调整强度则立即请求更新。显示恢复期间会等待捕获重新可用。

| 设置项 | 单位 / 可输入范围 | 新配置默认值 |
| --- | --- | --- |
| Monitor diagonal | 英寸；8–100 | 24 |
| Viewing distance | 厘米；20–300 | 60 |
| Pupil diameter | 毫米；2–8 | 6.5 |
| Effect strength | 百分比；0–100 | 70 |

这些是代码允许的范围，不是医学建议范围。默认值不是你的实测值，也不是研究验证的“安全剂量”。升级后会保留你已有的参数，不强制重置。

### 三个快捷键

Ctrl + Alt + F8：开启 / 关闭滤镜
Ctrl + Alt + ↑：强度增加 5 个百分点
Ctrl + Alt + ↓：强度降低 5 个百分点

托盘菜单的 Enabled 控制滤镜；Exit 完全退出程序。只有 Disable/快捷键关闭才会隐藏覆盖层；强度 0% 虽不改变颜色，仍可能经过捕获和呈现路径。

## 尺寸、距离、瞳孔、强度

### Monitor diagonal｜屏幕对角线

填写显示器规格中的对角线，单位英寸，例如 23.8、24 或 27。不是厘米，也不是屏幕横向宽度。分辨率由程序读取当前主显示器捕获尺寸，不需手动输入。不要按笔记本外壳尺寸填写。

### Viewing distance｜实际观看距离

填写眼睛到屏幕的实际距离，单位厘米。采用你正常坐姿下的大致距离，而不是椅子到桌子的距离。坐姿或屏幕位置明显改变后，可重新核对。不要为了“增强效果”填写比实际更远的距离。

### Pupil diameter｜瞳孔直径

瞳孔是虹膜中央的黑色小孔，不是整个深色“黑眼珠”（虹膜）。瞳孔大小会随照明等条件变化，软件不会自动测量或追踪。不要把常见的虹膜直径约 11–12 mm 填进来。

程序默认 6.5 mm 是计算假设，不代表你的实际瞳孔。若要比较此前参考的开源扩展，可在双方其他参数一致的情况下使用同一假设；这不构成临床等效验证。不了解自己的瞳孔大小时，应把数值视为估计，不能据此声称参数已经校准。专业测量更可靠。

### Effect strength｜滤镜混合比例

| 数值 | 程序含义 |
| --- | --- |
| 0% | 输出原图颜色，但软件覆盖路径仍可能运行 |
| 50% | 原图与滤镜输出各占一半 |
| 100% | 完整应用当前参数计算出的滤镜 |

强度不是视力改善量，也不是治疗剂量；100% 不代表“最好”。没有得到验证的最佳强度或使用时长，不要为了追求效果增加模糊，也不要通过修改瞳孔、距离来人为加码。

> **需要观察什么？**
> 只做短暂的功能对照，检查文字能否辨认、是否出现彩边或残影、操作是否正常。不适时立即关闭。视觉上更舒服，不等于已证明对近视有效；没有不适也不能证明长期安全。

## 算法含义与性能开关

### 滤镜实际做了什么

红通道保持原图；绿、蓝通道分别做全分辨率高斯低通，再按强度与原图混合。它不是把屏幕染红，也不是普通亮度或色温调节。

```text
像素尺寸（mm/px）= 对角线英寸 × 25.4 / 分辨率对角线像素数
σ（px）= 瞳孔mm × 距离mm × ΔD / 1000 / 像素尺寸 × 0.32
ΔD：绿 0.47；蓝 1.33
输出 = 原图 × (1 − 强度) + 滤镜图 × 强度
```

实现采用动态约 ±3σ 的离散核、双线性打包采样和边缘钳制，σ 上限为 32 px。它参考公开扩展的计算方式，但尚未与浏览器输出完成逐像素对照，也没有针对显示器的光谱或 MTF 校准。不能称为论文实验滤镜的精确复刻。

### 配置文件在哪里？

托盘右键 → Open config file… 打开实际生效的文件。通常位于 %LOCALAPPDATA%\MyopicDefocus\settings.ini。EXE 同目录若已有 MyopicDefocus.ini，则优先使用便携配置。

旧版 MyopicDefocusGPU.ini 或旧版 LocalAppData 配置会复制到新名称路径；旧文件保留。若目录不可写，会尝试沿用旧路径。两个配置并存时以新名称文件为准。

```ini
[Settings]
FrameLatencyWait=1
DirtyRects=1
```

FrameLatencyWait=1：请求 DXGI 帧延迟等待对象及最大排队延迟 1 帧；能否降低延迟取决于实际管线。不可用时自动回退，不能承诺固定节省多少毫秒。

DirtyRects=1：只重算变化区域及滤波邻域，减少部分渲染负载；并非所有场景都有收益。出现方块残影可改成 0 排查。修改这些开关需要重启。Renderer / dcomp 已不受支持。

设置窗口强度 70% 对应 INI 的 Strength=0.700，不是 Strength=70。GPU ms 是渲染耗时统计，不是端到端延迟；upd/s 是更新次数，桌面静止时低值正常。新计时口径不宜直接与旧版数值比较。

## 先恢复桌面，再反馈问题

### 异常时按这个顺序处理

1. Ctrl + Alt + F8 关闭滤镜。
2. 若无响应：Ctrl + Alt + Delete → 任务管理器，结束 MyopicDefocus.exe。
3. 不要同时重开多个版本；必要时保持软件退出，恢复正常桌面。

睡眠唤醒、锁屏、分辨率变化时，程序会隐藏覆盖层并尝试重建捕获。恢复过程中滤镜可能暂时消失。若仍出现黑屏、尺寸错误、输入被遮挡或反复失败，应退出并反馈，而不是持续 Enable 重试。

### 新版本的最低验证清单

□ 修改强度并 Save：全屏生效，不只跟随鼠标更新。
□ 滚网页、拖窗口、打开右键菜单：无明显方块残影。
□ 在输入框打字：观察 I-Beam 是否仍闪烁。
□ 睡眠 / 唤醒及锁屏 / 解锁：尺寸正确，无持续黑屏。
□ 关闭滤镜后，桌面操作和显示恢复正常。

1.3.5 已通过交叉编译、源码级参数/高斯核测试和部分生命周期静态检查。但它不是完成实机兼容性验收的稳定版；I-Beam 的反色合成问题仍未证实解决。渲染与 UI 仍在同一线程，显卡调用若长时间阻塞，快捷键也可能暂时失效。

### 反馈时提供什么

Windows 版本、显卡型号、主屏分辨率 / 缩放 / 刷新率、四个参数、性能开关，以及能够重复触发的步骤。诊断日志 MyopicDefocus.log 位于实际配置文件同目录，记录恢复错误，不记录屏幕图像或输入文字。日志不保证能捕获所有崩溃或阻塞。

> **医学边界**
> 相关论文是 10 人的短期先导研究，不能验证这款程序的长期安全性或疗效。出现持续视力变化、眼痛、复视或其他明显不适时停用并咨询眼科专业人员。不要替代正常用眼休息、眼科检查或已有治疗方案。
